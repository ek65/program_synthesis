# README

**translator.py** contains a Python-based translator that reads a JSON specification of "actions" and "constraints" to generate:

1. A text-based **coach behavior** script.
2. Python function definitions (lambdas) representing logical constraints for each action.

Below is an outline of the code’s structure and how the functions are organized. An example usage is provided in the `main()` function.

---

## High-Level Structure

1. **Constraint Classes**  
   - **InZone, HasAngle, IsVisible, DistanceLessThan, DistanceGreaterThan**  
    Each class represents a particular type of constraint (distance checks, visibility checks, angle checks, etc.).
2. **`construct_coach_behavior(action_json)`**  
   - **Purpose**: Generates a multi-line **coach behavior** script from a list of actions.  
   - **Process**:  
     - Iterates over each action in `action_json["actions"]`.  
     - Depending on the action type (`moveTo`, `Idle`, `passTo`, etc.), constructs lines such as:
       ```
       do moveTo(...) until ...
       do Idle() until ...
       do passTo(...)
       ```
     - Returns a string containing all these lines, prefixed with `behavior coachBehavior():` and `scene = simulation()`.

3. **`synthesize_conditionals(expression)`**  
   - **Purpose**: Converts logical expressions (e.g., `"IF A THEN B ELSE (C AND D)"`) into Pythonic conditionals (e.g., `"(B if A else (C and D))"`) and replaces `"AND"/"OR"` with `"and"/"or"`.  
   - **Usage**: Ensures expressions in the JSON can be represented as valid Python expressions.

4. **`get_args(action, constraint_name)`**  
   - **Purpose**: For a given action and constraint key (like `"λ_precondition"`), extracts the `"args"` block and produces lines of Python code that instantiate the appropriate constraint classes.  
   - **Example**:  
     If the JSON has:
     ```json
     "args": {
       "A": { "type": "InZone", "args": {"zone": "C1"} },
       "B": { "type": "HasAngle", "args": {"ref": "player", "r": 1.5} }
     }
     ```
     `get_args()` returns something like:
     ```
     A = InZone({'zone': 'C1'})
     B = HasAngle({'ref': 'player', 'r': 1.5})
     ```

5. **`create_constraint_definitions(action_index, example)`**  
   - **Purpose**: Gathers all constraint definitions for the action at a given index.  
   - **Process**:
     - Looks up the action via `example["actions"][action_index]`.
     - For each constraint name, calls `get_args(...)` to produce lines of Python code like `A = InZone(...)`.

6. **Lambda Creation Functions**  
   - **`create_lambda_dest(action)`**  
     Builds a Python function `λ_dest` for handling an action’s “destination” logic.  
   - **`create_lambda_termination(action)`**  
     Builds a Python function `λ_termination` for an action’s “termination” logic.  
   - **`create_lambda_precondition(action)`**  
     Builds a Python function `λ_precondition` for an action’s “precondition” logic.  
   - **Shared Process**:
     - Reads a logical expression from the JSON.
     - Calls `synthesize_conditionals(...)` to convert it into Python syntax.
     - Substitutes placeholders (like `"A"`, `"B"`) with function calls (e.g., `A(scene, sample)`).
     - Returns the final function definition as a string.

7. **`generate_all_constraints_and_lambdas(example)`**  
   - **Purpose**: Prints out the constraint definitions (as generated by `create_constraint_definitions`) and any lambda functions (`λ_precondition`, `λ_dest`, `λ_termination`) for each action.
   - **Usage**: Helpful for debugging or demonstrating how each action’s logic is translated.

8. **`main()`**  
   - **Purpose**: Contains a sample JSON structure and demonstrates calling the above functions:
     - Prints a coach behavior script.
     - Prints constraint definitions and lambda functions.

---

## Example of Generated Output

Running the example code in `main()` might produce something like:
 ```
behavior coachBehavior():
    scene = simulation()
    do Idle() until λ_precondition
    do moveTo(λ_dest) until λ_termination
    do Idle() until λ_precondition
    do passTo(teammate)
 ```

Followed by detailed constraint definitions and lambda function code, for instance:
```
### Constraints and Lambda Functions for Action 1: Idle
A = InZone({'zone': 'C1'})
B = HasAngle({'ref': 'player', 'r': 1.5})
def λ_precondition(scene, sample):
    return A(scene, sample) and B(scene, sample)

def λ_dest(scene, sample):
    return None  # No logical expression provided

def λ_termination(scene, sample):
    return None  # No logical expression provided
...
```
